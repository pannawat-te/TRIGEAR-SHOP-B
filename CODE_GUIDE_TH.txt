ทุกไฟล์ Python มี # ไฟล์นี้ อธิบายหน้าที่
ก่อนแต่ละ class มี # คลาส อธิบายส่วนที่ดูแล
ก่อนแต่ละ def มี # def อธิบายขั้นตอนและผลลัพธ์
# เป็นคอมเมนต์ Python ไม่เรียกทำงาน
self คือข้อมูลและฟังก์ชันของออบเจ็กต์ปัจจุบัน
__init__ ทำงานเมื่อสร้างหน้า/ออบเจ็กต์
build สร้างช่องกรอก ปุ่ม และตาราง
command=ชื่อฟังก์ชัน ผูกปุ่มกับการทำงานเมื่อกด
bind ผูกเหตุการณ์ เช่น เลือกแถว หรือกด Enter
callback คือฟังก์ชันที่ส่งให้เรียกภายหลัง เช่น กลับหน้าก่อน
execute อ่านหรือแก้ฐานข้อมูล; ? คือช่องแทนค่าพารามิเตอร์
commit ยืนยันการบันทึก; rollback ยกเลิกธุรกรรมที่ไม่สำเร็จ

หาไฟล์ตามงาน:
main.py เปิดโปรแกรม
database/database.py ตารางและการเริ่มฐานข้อมูล
ui/login.py หน้าเข้าสู่ระบบ
ui/register.py สมัครสมาชิก
ui/customer_home.py หน้าร้าน/รายละเอียดสินค้า
ui/cart.py ตะกร้า
ui/checkout.py ชำระเงิน/หน้าสรุป
ui/orders.py ประวัติลูกค้า
ui/account.py บัญชี/ที่อยู่
ui/admin/dashboard.py เมนู Admin
ui/admin/products.py สินค้า
ui/admin/size_editor.py ไซซ์และจำนวน
ui/admin/orders.py ตรวจสลิป/จัดส่ง/คืนเงิน
ui/admin/members.py ข้อมูลสมาชิก
ui/admin/password_resets.py คำขอรีเซ็ตรหัส
database/password_reset.py กระบวนการรีเซ็ตรหัส
