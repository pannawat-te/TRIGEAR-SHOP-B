TRIGEAR — ปรับหน้า Admin + แก้ตะกร้าค้าง
ฐาน: TRIGear - Copy.zip ที่ส่งล่าสุด พร้อมแพตช์ Noto Sans Thai และ Login ก่อนหน้า

ติดตั้ง
1. ปิดโปรแกรม สำรองโฟลเดอร์โปรแกรมเดิมไว้ก่อน
2. แตก ZIP นี้ แล้ววาง ui และ tests รวมในโฟลเดอร์ที่มี main.py เดิม
3. เลือกแทนที่ไฟล์ชื่อเดียวกัน ห้ามลบโฟลเดอร์ ui เดิม
4. รัน py main.py ตามเดิม ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม
ต้องเก็บไฟล์ *_base.py และ modern_style.py ที่แนบไปด้วย เพราะหน้าจอใหม่เรียกใช้ฟังก์ชันเดิมจากไฟล์เหล่านี้

แก้ตะกร้า
พบและทำซ้ำอาการค้างได้เมื่อมีสินค้าที่เลือกไซส์: callback Configure ของชื่อสินค้าเรียกปรับ wraplength ของปุ่ม CTk ระหว่างจัดขนาด widget และ CTkOptionMenu/Scrollbar ประมวลผล idle ซ้อนกัน ทำให้การวาดไม่จบ
เปลี่ยนชื่อสินค้าเป็นข้อความคลิกได้ที่ตัดบรรทัดโดยไม่ผูกการปรับขนาดกลับไปหาตัวเอง และรวมการแจ้งตำแหน่ง Scrollbar ให้ส่งครั้งเดียวต่อเฟรม พร้อมยกเลิก callback เมื่อปิดหน้า
คงการโหลดตะกร้าถาวร แยกผู้ใช้ เลือกซื้อ เพิ่มลด เปลี่ยนไซส์ และคำนวณ VAT เดิม

หน้า Admin
- Dashboard: เมนูซ้ายสีขาว การ์ดยอดรับชำระ/ออเดอร์/รอตรวจสลิป/ใกล้หมด กราฟแนวโน้มและวงแหวนสถานะ วันที่/ปฏิทิน/วันนี้/เดือนนี้/ปีนี้ อันดับสินค้าขายดีมีช่วงเวลาและหมวดของตนเอง
- สินค้า: ค้นหาชื่อ/แบรนด์ หรือ ID ตัวเลข กรองหมวดรวมหมวดย่อย/สถานะสต๊อก รูปย่อ ตารางแบ่งหน้า 9 รายการ ดู/แก้ไข/ลบตามสินค้าที่เลือก เตือนรายสินค้า/ไซส์เมื่อเหลือ 0–3 และอัปเดตคำเตือนทุก 5 วินาที
- เพิ่มและแก้ไขสินค้าเปิดเป็นหน้าแยก เก็บระบบแกลเลอรี ประเภทไซส์ ตารางไซส์ หมวดหลายรายการ สินค้าแนะนำ และธุรกรรมบันทึกสินค้าเดิม
- คำสั่งซื้อ: ค้นหา กรองสถานะ/วันที่ แบ่งหน้า 9 รายการ เลือกรายการแล้วกดตรวจสลิป/จัดการ/ดูรายละเอียด/คืนเงิน หรือดับเบิลคลิกดูรายละเอียด
- หน้ารายละเอียดมีปุ่มดูสินค้าแบบ popup ยอดก่อน VAT/ภาษี/ยอดรวมตามออเดอร์จริง ใบเสร็จ และเลขพัสดุที่บันทึกแล้ว
- ตรวจสลิป/ยืนยันออเดอร์ใช้เงื่อนไขรับเงิน ออกเลขใบเสร็จ และตัดสต๊อกเดิม
- จัดส่ง: ระบุขนส่ง/เลขพัสดุ ตรวจสถานะใน transaction แล้วบันทึกพร้อมเปลี่ยนสถานะ ตาราง admin_shipments ถูกเพิ่มแบบไม่ลบข้อมูล เฉพาะเมื่อยืนยันจัดส่งครั้งแรก
- คืนเงิน: แสดงบัญชีตามออเดอร์ แนบภาพหลักฐาน ตรวจว่าได้รับเงินจริง/ยังรอคืนเงิน และยืนยันก่อนบันทึก ไม่โอนเงินอัตโนมัติ ไม่คืนเงินซ้ำ
- เมนูสมาชิก/รีเซ็ตรหัส/อีเมลเชื่อมหน้าที่มีอยู่เดิม ยังไม่ได้ออกแบบเนื้อหาของสามหน้านั้นใหม่
ใช้แนวทางสี รูปทรง และการแยกหน้าตามภาพตัวอย่าง ตารางจริงยังใช้ Tk/ttk เพื่อรองรับรายการ การเลือก คีย์บอร์ด และแถบเลื่อนเดิม ไม่ใช่ภาพกราฟิกแทนหน้าจอ

ข้อมูล
ไม่มีฐานข้อมูล รูปสินค้า สลิป อีเมล หรือข้อมูลผู้ใช้ใน ZIP นี้ ไม่ทับไฟล์ข้อมูลร้าน
ยอดขายอ้างอิงรายงานเดิม: รับชำระตามวันสร้างออเดอร์ คืนเงินตามวันคืนจริง ไม่แก้ยอดออเดอร์เก่าย้อนหลัง

ตรวจสอบแล้ว
ใช้ฐานข้อมูลตัวอย่างแยก ไม่เปิดหรือแก้ฐานข้อมูลร้านจริง
Tk/CustomTkinter จริงบน Linux: หน้า Admin ที่ความกว้าง 1000/1440, เพิ่ม/แก้ไขสินค้า, เปิดรายละเอียด/OTP เดิมไม่เกี่ยวข้องกับแพตช์นี้, กรอง/แบ่งหน้า, ดูสินค้าต่อออเดอร์, บันทึกขนส่งและพัสดุ, ยืนยันชำระเงิน/ออกเลขใบเสร็จ/ตัดสต๊อก, แนบหลักฐานคืนเงิน
ตะกร้าทั้งสินค้าไม่มีไซส์และมีไซส์ ที่ 1000/1440/1920: เพิ่มลด เลือกรายการ กดกลับ ไม่ค้าง ไม่พบ callback error
