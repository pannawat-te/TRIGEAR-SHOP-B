ติดตั้ง: py -m pip install -r requirements.txt
เริ่ม: py main.py

Admin อนุมัติการชำระเงิน: ออกเลขและเก็บข้อมูล ณ เวลาออกอัตโนมัติ
ลูกค้า: ประวัติคำสั่งซื้อ > ดู / บันทึกใบเสร็จ
Admin: จัดการคำสั่งซื้อ > เลือก Order > ดู / บันทึก / พิมพ์ใบเสร็จ
Order เก่าที่รับเงินแล้ว: เปิดใบเสร็จเพื่อออกครั้งแรกโดยใช้ข้อมูลปัจจุบันที่มีอยู่ (ไม่มีข้อมูล snapshot ย้อนหลัง)
Order ยกเลิก/รอคืนเงิน: ไม่ออกใบเสร็จใหม่ ใบเสร็จเดิมเก็บไว้พร้อมแจ้งสถานะในหน้าดู
PDF เก็บใน uploads/receipts หากไฟล์หายสร้างใหม่จากข้อมูลเดิมได้
ไม่มีการส่งอีเมล และไม่มีเลขผู้เสียภาษีที่แต่งขึ้น

สำรอง database/shop.db และ uploads ก่อนอัปเดต ห้ามทับฐานข้อมูลและ uploads จริงด้วยข้อมูลตัวอย่างใน ZIP
ไฟล์เพิ่ม: services/receipt.py, services/__init__.py, ui/receipt_view.py, assets/receipt_logo.png, assets/fonts/*
ไฟล์แก้: database/database.py, ui/orders.py, ui/admin/orders.py, requirements.txt
ผ่าน Syntax และทดสอบเลขซ้ำ snapshot สิทธิ์ลูกค้า สถานะยกเลิก และ PDF หลายหน้า
ตรวจภาพ PDF ภาษาไทยแล้ว ยังไม่ได้ทดสอบ GUI/การพิมพ์บน Windows
