แก้ปฏิทินไม่เห็นตัวเลข
ปิดโปรแกรม แล้วนำโฟลเดอร์ ui ใน ZIP วางรวมในโฟลเดอร์โปรแกรม เลือกแทนที่เฉพาะ ui/date_picker.py อย่าลบ ui เดิม จากนั้นรัน py main.py
ใช้ได้กับหน้า Dashboard เดิมและหน้า Admin ใหม่ ทุกจุดที่เรียกปฏิทินร่วมกัน ไม่ต้องติดตั้งเพิ่ม
กำหนดสีตัวเลข/พื้นปุ่ม/สถานะเลือกและโฟกัสให้ชัดเจน ไม่รับสีขาวจากธีมปุ่มหลัก แสดงชื่อเดือนไทย ปี ค.ศ. เก็บค่า YYYY-MM-DD ตามเดิม เพิ่มปุ่มวันนี้และยกเลิก วางหน้าต่างกลางโปรแกรม
ไม่มีฐานข้อมูลหรือรูปภาพ ไม่แก้ยอดขายหรือข้อมูลคำสั่งซื้อ
ทดสอบหน้าต่าง Tk จริงบน Linux ภายใต้ธีมตัวหนังสือปุ่มสีขาว ตรวจจำนวนวัน สีตัวเลข เปลี่ยนเดือนธันวาคมข้ามปี เลือกวัน และยกเลิกแล้วไม่เปลี่ยนค่า ผ่านทั้งหมด ยังไม่ได้ทดสอบ Windows จริง
