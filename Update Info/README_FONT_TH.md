แพตช์ Noto Sans Thai สำหรับ TRIGear - Copy.zip ที่ส่งมาล่าสุด

วิธีใช้
1. ปิดโปรแกรมและสำรองโฟลเดอร์เดิม
2. แตก ZIP แล้วนำ main.py, ui และ assets วางรวมในโฟลเดอร์โปรแกรมที่มี main.py เดิม
3. เลือกแทนที่ไฟล์ชื่อเดียวกัน อย่าลบโฟลเดอร์ ui หรือ assets เดิม
4. รัน py main.py ตามเดิม ไม่ต้องติดตั้งฟอนต์ใน Windows

ปรับฟอนต์หน้าร้าน รายละเอียดสินค้า หน้าเข้าสู่ระบบ สมัครสมาชิก ตะกร้า ชำระเงิน บัญชี และหน้าแอดมินที่กำหนดฟอนต์ไว้ รวมถึงฟอนต์เริ่มต้น Tk/ttk/CustomTkinter
แนบ Noto Sans Thai Regular/Bold พร้อมใบอนุญาต OFL
ปุ่มหน้าร้านสูง 44px ตัวอักษร 16px ชื่อสินค้า 12pt (ประมาณ 16px ที่ 96 DPI) และพื้นที่ชื่อขยายตามข้อความ
ฟอนต์และขนาดของใบเสร็จ PDF ไม่เปลี่ยน

แพตช์ไม่มีฐานข้อมูล ข้อมูลผู้ใช้ รูปสินค้า หรือค่าตั้งอีเมล
ทดสอบลงทะเบียนฟอนต์จริงบน Linux และเปิดหน้าร้าน/รายละเอียดสินค้าที่ความกว้าง 1000 และ 1440px ผ่าน ไม่พบ callback error
ยังไม่ได้ทดสอบ Windows จริง และยังไม่ได้ตรวจทุกหน้าจอด้วยสายตา
