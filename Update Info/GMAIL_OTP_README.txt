TRIGEAR — Gmail OTP (เครื่องร้านเครื่องเดียว)

เริ่มใช้งาน
1. สำรองโฟลเดอร์เดิมก่อน แล้วแตก ZIP นี้เป็นโฟลเดอร์ใหม่
2. เปิด main.py ด้วย Python/virtual environment ที่เคยใช้งาน
3. เข้าระบบ Admin > ตั้งค่าอีเมล OTP
4. ใส่ Gmail ผู้ส่งและ App Password แล้วบันทึก
5. ทดสอบสมัครบัญชีด้วยอีเมลของคุณเอง ตรวจทั้ง Inbox และ Spam

สมัครสมาชิก
กรอกข้อมูลแล้วกดส่ง OTP ระบบยังไม่สร้างบัญชีจนกว่าจะยืนยันรหัสสำเร็จ
ถ้าต้องการส่งซ้ำ ปิดหน้าต่าง OTP แล้วกดส่งใหม่หลังรอ 60 วินาที

ลืมรหัสผ่าน
ลูกค้าส่งคำขอ > Admin ตรวจสอบเจ้าของบัญชีและติ๊กยืนยัน > อนุมัติและส่ง OTP
ลูกค้าเปิดหน้าลืมรหัส > ได้รับ OTP แล้ว / ตั้งรหัสผ่านใหม่
กรอก Username อีเมลเดิม OTP และรหัสใหม่
รหัสผ่านเดิมยังใช้ได้จนกว่าลูกค้าจะตั้งรหัสใหม่สำเร็จ
ส่งไม่สำเร็จให้ Admin ตรวจการตั้งค่าและส่งซ้ำหลัง 60 วินาที
Admin ส่งซ้ำได้จากคำขอที่มีสถานะส่ง OTP แล้ว ถ้ายังไม่ได้ใช้รหัส
ปฏิเสธคำขอจะยกเลิก OTP ของคำขอนั้นด้วย
คำขอของ Admin ต้องให้ Admin อีกคนอนุมัติ

OTP: 6 หลัก อายุ 10 นาที ใช้ครั้งเดียว กรอกผิดได้สูงสุด 5 ครั้ง
ส่งใหม่จะยกเลิกรหัสเก่า ไม่แสดง OTP ให้ Admin และไม่บันทึกรหัส OTP ที่อ่านได้
ฐานข้อมูลใหม่จะเพิ่มตาราง email_otps เมื่อเปิดโปรแกรมครั้งแรก
บัญชีเดิมยังเข้าใช้งานได้ ไม่บังคับยืนยันอีเมลย้อนหลัง
รองรับรหัสชั่วคราวที่ออกโดยระบบเดิมจนกว่าจะหมดอายุ

การเก็บค่าของเครื่องร้าน
config/smtp.local.json เป็นไฟล์ที่ระบบสร้างหลังบันทึกการตั้งค่า
ไฟล์นี้มี App Password ให้อยู่เฉพาะเครื่องร้าน ห้ามแนบไปใน ZIP หรือส่งให้ผู้อื่น
ถ้าย้ายโฟลเดอร์ ให้ตั้งค่า Gmail ใหม่ หรือคัดลอกไฟล์นี้เองเฉพาะเครื่องร้าน
อย่าเผยแพร่ App Password ในภาพหน้าจอ/แชท

การตรวจสอบ
ผ่านการทดสอบ logic OTP และ SMTP แบบจำลอง ไม่ได้ส่งเมลจริงจากบัญชีร้าน
ยังไม่ได้ทดสอบหน้าต่าง Tkinter บน Windows จริง
ฐานข้อมูล รูปภาพ และฟอนต์ใน ZIP นี้ตรงกับ ZIP ต้นฉบับที่ส่งมา
ถ้ามีการเพิ่มสินค้า/ผู้ใช้หลังจากส่ง ZIP นี้ อย่าแทนฐานข้อมูลใหม่ด้วยฐานข้อมูลใน ZIP นี้
