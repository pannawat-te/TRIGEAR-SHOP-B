TRIGEAR — ตะกร้าถาวรจาก ZIP ผู้ใช้ล่าสุด
เก็บสินค้า ไซซ์ จำนวน และช่องติ๊กแยกบัญชีใน SQLite
เพิ่ม/ลด/ลบ/เลือกสินค้า บันทึกทันที โหลดกลับเมื่อเปิดโปรแกรมและเข้าหน้าร้าน
สั่งสำเร็จลบเฉพาะรายการซื้อ รายการไม่เลือกคงอยู่
ลบรายการซื้อใน transaction เดียวกับ Order สั่งล้มเหลวตะกร้าไม่หาย
ฐานข้อมูลเพิ่ม cart_items อัตโนมัติเมื่อเปิดโปรแกรม ข้อมูลเดิมไม่ล้าง
ไฟล์ใหม่ database/cart_store.py
ไฟล์แก้ database/database.py, ui/cart.py, ui/checkout.py, ui/customer_home.py
ฐานข้อมูลและรูปจาก ZIP คงเดิม ตรวจ SHA256 ตรงต้นฉบับ
ทดสอบเริ่ม process ใหม่ โหลดจำนวน/ไซซ์/ติ๊ก แยกผู้ใช้ การลบรายการซื้อ rollback และกันตะกร้าเปลี่ยนระหว่างสั่ง
ผ่าน Syntax ยังไม่ได้ทดสอบ GUI Windows
สำรอง database/shop.db และ uploads ก่อนอัปเดต หากมีข้อมูลใหม่แทนเฉพาะไฟล์โค้ด5ไฟล์ อย่าทับ DB
รายการในตะกร้าที่หายก่อนอัปเดตต้องเพิ่มใหม่ ไม่มีข้อมูลเก็บไว้ให้กู้
