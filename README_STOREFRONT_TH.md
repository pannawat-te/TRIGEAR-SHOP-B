# TRIGEAR — หน้าร้าน CustomTkinter / Slide / Smooth Scroll

ชุดนี้ปรับจาก ui.zip และ main.py ที่คุณส่งมารอบล่าสุดโดยตรง
ปรับเฉพาะหน้าร้านและรายละเอียดสินค้า พร้อมตัวเลื่อนเมาส์ที่ใช้ร่วมกัน หน้าอื่นยังใช้ UI เดิม เพื่อให้ทดลองสองหน้านี้ก่อน

## วางไฟล์อย่างไร
1. ปิดโปรแกรม TRIGEAR ทุกหน้าต่าง และเก็บสำเนา main.py กับโฟลเดอร์ ui เดิมไว้ก่อน
2. แตก ZIP นี้ แล้วคัดลอกไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้าง README นี้ ไปวางรวมในโฟลเดอร์ TRIGear เดิม ซึ่งมี main.py, ui, database, assets และ services
3. เลือกแทนที่ไฟล์ชื่อเดียวกัน แต่ **ไม่ลบโฟลเดอร์ ui เดิม** เพราะชุดนี้ส่งกลับเฉพาะไฟล์ที่แก้หรือเพิ่ม ต้องใช้ไฟล์ UI อื่นจากเครื่องคุณร่วมด้วย
4. เปิด INSTALL_STOREFRONT.bat เพื่อติดตั้ง CustomTkinter และ Pillow ใน Python ที่คำสั่ง py ใช้ ไม่ติดตั้ง OpenCV
5. เปิด Terminal ที่โฟลเดอร์ TRIGear แล้วรัน `py main.py` หรือใช้ START_TRIGEAR.bat เดิมที่เรียก py main.py
6. ล็อกอินบัญชีลูกค้าเพื่อดูหน้าร้านใหม่

ไม่มีโฟลเดอร์ database, services, assets, uploads หรือข้อมูลสมาชิกในแพตช์นี้ จึงไม่ทับข้อมูลร้าน
หากคุณใช้ .venv ต้องติดตั้ง requirements-storefront.txt และรัน main.py ด้วย Python ใน .venv ตัวเดียวกัน

## สิ่งที่ปรับ
- หน้าร้านจัดใหม่เป็นเมนูหมวดซ้ายและพื้นที่สินค้าขวา ใช้การ์ดกับปุ่มมุมมนของ CustomTkinter จริง
- ชื่อสินค้าอยู่กึ่งกลางทั้งบรรทัดเดียวและหลายบรรทัด ชื่อยาวปรับความสูงร่วมกันเพื่อให้ปุ่มตรงกันและอ่านข้อความครบ
- ปุ่มดูรายละเอียดและเพิ่มตะกร้าอยู่คู่กัน รูปสินค้าใหญ่ขึ้น ภาพย่อในการ์ดลดเฉพาะขอบขาวว่าง ส่วนภาพต้นฉบับในรายละเอียดแสดงครบ
- สินค้าแนะนำยังสูงสุด 6 รายการ และรายการสินค้า/ผลค้นหา/หมวดหมู่ยังแบ่งหน้าละ 9 รายการ
- จอแคบเปลี่ยนเป็น 2 คอลัมน์ แต่จำนวนสินค้าต่อหน้ายังเท่าเดิม
- หน้ารายละเอียดมีภาพใหญ่ แกลเลอรี ตัวเลือกไซส์มุมมน ปุ่มตารางไซส์ จำนวน และรายละเอียดพร้อมลิงก์เดิม
- ภาพหลักในแกลเลอรี Slide แนวนอน 300ms แบบ Ease-out เฉพาะตอนเปลี่ยนรูป ไม่เลื่อนทั้งหน้าจอ
- เมื่อคลิกรัวหรือกลับหน้าอื่น ยกเลิกแอนิเมชันเก่า ไม่สะสมคิวหลังออกจากหน้า
- Smooth Scroll สำหรับ Canvas: ค่อย ๆ ไปยังตำแหน่งเป้าหมายในประมาณ 160ms รับการหมุนต่อเนื่องและกลับทิศได้ ขอบเขตเลื่อนไม่เกินเนื้อหา
- พื้นที่ Text, Listbox, ตาราง และตัวเลือกแบบ native ยังรับล้อเมาส์ของตัวเอง ไม่แย่งการควบคุมจากวิดเจ็ตเหล่านั้น
- ยังคงปุ่มตะกร้าแบบข้อความ จำนวนรวม รูปโปรไฟล์ และปุ่มออกจากระบบที่เห็นชัด
- main.py คงระบบตรวจบัญชีถูกระงับ check_session และ session เดิม เพิ่มเพียงการแจ้งติดตั้ง CustomTkinter เมื่อยังไม่มี รูปแบบเต็มจอ Esc/F11 เดิมคงอยู่

## การตรวจสอบ
ทดสอบกับฐานข้อมูลตัวอย่างแยกและ CustomTkinter 6.0.0 ไม่เปิดหรือแก้ฐานข้อมูลร้านจริง
เปิดหน้าจอ Tk/CTk จริงบนจอทดสอบ Linux และตรวจทั้งความกว้าง 1000 และ 1440 พิกเซล
ตรวจการแบ่งหน้า การเรียงราคา เลือกไซส์ Smooth Scroll เปลี่ยนภาพ 300ms คลิกรัวและปิดหน้าขณะเคลื่อนไหว
ชุดทดสอบ Smooth Scroll แบบจำลองเวลา: `py tests/test_smooth_scroll.py`
ยังไม่ได้ทดสอบบน Windows เครื่องของคุณ ฟอนต์และ DPI อาจทำให้ระยะต่างกันได้
